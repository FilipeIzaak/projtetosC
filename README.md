# Atividades em C

Repositório contendo exercícios, atividades e práticas desenvolvidas em linguagem C durante os estudos de programação e lógica computacional.

O objetivo deste repositório é registrar a evolução técnica e reforçar conceitos fundamentais utilizados no desenvolvimento de software.

## Conteúdos abordados

- Estruturas condicionais
- Estruturas de repetição
- Vetores e matrizes
- Funções
- Ponteiros
- Manipulação de dados
- Lógica de programação
- Estruturas básicas de algoritmos

## Tecnologias utilizadas

- Linguagem C
- GCC
- VS Code / Dev-C++

## Objetivos do repositório

- Praticar lógica de programação
- Fortalecer base computacional
- Desenvolver raciocínio algorítmico
- Aprender fundamentos de programação procedural
- Registrar evolução nos estudos
